# Voice AI benchmarks

Benchmarks of voice-AI agent platforms, measured over real phone calls with [VAATT](https://github.com/team-telnyx/vaatt).

## Runs

| Run | Measured | Headline | Platforms |
|---|---|---|---|
| [2026-10 first-response latency](2026-10-first-response-latency/) | Time from the caller's last sound to the agent's first sound | Telnyx and Retell about 0.9–1.0 s, ElevenLabs about 1.3 s, LiveKit about 1.8 s, Vapi about 2.2 s | Telnyx, Retell, ElevenLabs, LiveKit, Vapi |

New runs go in a new folder here and get a row in the table above. See the [root README](../README.md) for the folder layout and what each run's README should say.
